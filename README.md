# Rival Surge

A browser-based 3D tactical FPS inspired by Roblox Rivals, built as a fast prototype arena shooter.

Features:
- First-person pointer-lock controls with strafe movement and arena traversal
- Tactical objective zone in the center of the map
- Rifle and shotgun loadout swap with reload and ammo management
- Enemy bots that flank, press, and fire at the player
- Score, health, armor, timer, and round progression HUD

How to run:
1. In the project folder, run `python3 -m http.server 8000`
2. Open `http://localhost:8000/Index.html` in a modern browser
3. Click to deploy and start playing

Controls:
- WASD: move
- Mouse: look around
- Left click: fire
- Q: switch weapons
- R: reload

Notes:
- This is a lightweight playable prototype designed for fast iteration and local play.
- It can be expanded with multiplayer, loadouts, abilities, or larger objective maps.
